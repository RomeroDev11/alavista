# Ala Vista

**Ala Vista** es un catálogo de las 58 especies de aves del humedal Conejera (Uzhe Tibacuy, Bogotá) para marcar las que has visto. Funciona sin conexión y se instala como app en el celular.

## Publicar con GitHub Pages (enlace gratuito)

1. En github.com toca **New repository**. Nombre sugerido: `ala-vista`. Déjalo **Public** y crea el repositorio.
2. Toca **uploading an existing file** y arrastra **el contenido** de esta carpeta (index.html, sw.js, manifest.webmanifest y las carpetas fonts, icons e img). Son unos 80 archivos, dentro del límite de 100 por subida. Toca **Commit changes**.
3. Ve a **Settings → Pages**. En *Source* elige **Deploy from a branch**, rama **main**, carpeta **/ (root)** y guarda.
4. En uno o dos minutos la página aparece en `https://TU-USUARIO.github.io/ala-vista/`.

## Instalar en el celular

Abre el enlace **con conexión** al menos una vez, para que la app se guarde en el teléfono.

- **Android (Chrome):** menú ⋮ → *Instalar app* o *Añadir a pantalla de inicio*.
- **iPhone (Safari):** botón Compartir → *Añadir a pantalla de inicio*.

## Alternativa rápida sin GitHub

Entra a app.netlify.com/drop y arrastra esta carpeta: devuelve un enlace al instante. Crea una cuenta gratuita para que el enlace no caduque.

## Tus datos

Los avistamientos se guardan solo en el dispositivo donde los marcas. Cada persona que abra el enlace tiene su propia lista. Usa **Mis datos → Guardar copia de seguridad** de vez en cuando; ahí también puedes restaurar la copia o exportar a CSV.
